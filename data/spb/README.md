# Исследования источников данных о метро Санкт-Петербурга

Каждая дочерняя папка — самостоятельное исследование одного источника: README с выводами, автономный
скрипт выгрузки (`fetch-data.js`, ванильный Node.js 18+, без зависимостей) и скачанные данные. Структура
повторяет московские исследования в `../mos/`.

| Папка | Источник | Что даёт |
|---|---|---|
| `spb-metrobook-ru/` | https://spb.metrobook.ru/ | Взвешенный граф: вершины «станция × линия», перегоны и пересадки со временем в секундах; плюс `route-cli.js` — автономный расчёт маршрута |
| `hh-ru/` | https://api.hh.ru/metro/2 | Открытое документированное API: линии (имена, цвета), 75 станций с координатами и порядком; единственный машиночитаемый источник линии 6 |
| `metro-spb-ru/` | https://metro.spb.ru/rejimrabotystancii.html | Официальный режим работы вестибюлей, первые/последние поезда по чётным/нечётным датам, выходы, закрытия; TLS через закреплённый сертификат Минцифры |

Общая картина источников и отвергнутые кандидаты (GTFS без метро, Яндекс Метро за CSRF и другие) —
в обзорном документе `2026-07-26_21-43--spb_metro_data_sources.md`; постановка задачи —
`2026-07-26_21-43--prompt-spb.md`.

Боевой код, собирающий эти же источники в единый датасет с достройкой линии 6, —
`src/lib/metro-data/{fetch-spb-hh,fetch-spb-official,spb-official-tls,normalize-spb,refresh-spb}.ts`.
