# api.hh.ru как справочник станций метро Санкт-Петербурга

Открытое **документированное** API HeadHunter отдаёт справочник метро для 12 городов России; для
Санкт-Петербурга достаточно **одного запроса** `GET https://api.hh.ru/metro/2` (2 — идентификатор города,
Москва — 1). Авторизация не требуется, нужен лишь непустой `User-Agent`. Это единственный из наших
петербургских источников с официальной документацией:
https://api.hh.ru/openapi/redoc#tag/Obshie-spravochniki

## Что содержит ответ

Объект города со списком линий; у каждой линии — идентификатор, цвет и станции в путевом порядке:

```json
{ "id": "2", "name": "Санкт-Петербург",
  "lines": [
    { "id": "14", "hex_color": "D6083B", "name": "Кировско-Выборгская",
      "stations": [
        { "id": "14.190", "name": "Девяткино", "lat": 60.050182, "lng": 30.443045, "order": 0 },
        ...
      ] },
    ... ] }
```

В выгрузке от 26.07.2026: **6 линий, 75 станций**, у всех станций есть координаты:

| id линии hh | Название | Цвет | Станций | Публичный номер |
|---|---|---|---|---|
| 14 | Кировско-Выборгская | #D6083B | 19 | 1 |
| 15 | Московско-Петроградская | #0078C9 | 18 | 2 |
| 16 | Невско-Василеостровская | #009A49 | 12 | 3 |
| 17 | Лахтинско-Правобережная | #EA7125 | 9 | 4 |
| 18 | Фрунзенско-Приморская | #702785 | 15 | 5 |
| 170 | Красносельско-Калининская | #8C5646 | 2 | 6 |

Ключевые поля станции: `name` (русское название), `lat`/`lng` (координаты), `order` — порядковый номер
станции на линии в путевом порядке (0 — конечная). Идентификатор станции имеет вид `<линия>.<номер>`
(например `14.190`).

**Важно:** идентификаторы линий hh.ru (14–18, 170) — внутренние; публичным номерам линий метрополитена
(1–6) они не равны, но однозначно сопоставляются по составу станций (в боевом коде — голосованием по
совпадению названий, `src/lib/metro-data/normalize-spb.ts`).

## Чего в справочнике нет

- времён перегонов и пересадок (граф для маршрутизации отсюда не построить);
- режима работы станций и расписаний;
- сведений о закрытиях: **закрытые на реконструкцию «Фрунзенская» и «Парк Победы» числятся как обычные
  станции** без каких-либо пометок;
- переходов между линиями (пересадочные узлы никак не связаны);
- английских названий.

## Роль в проекте

Источник обогащения поверх графа `../spb-metrobook-ru/`: координаты всех станций, официальные названия
и цвета линий, порядок станций. Кроме того, это единственный машиночитаемый источник, где присутствует
**линия 6** (Красносельско-Калининская: «Юго-Западная», «Путиловская»), отсутствующая на схеме metrobook, —
из него берётся её топология и координаты. Сопоставление станций со схемой metrobook — 73 из 73 по
нормализованному названию (приведение к нижнему регистру, «ё» → «е»).

## Файлы в этой папке

| Файл | Назначение |
|---|---|
| `fetch-data.js` | Скачивает справочник (один запрос) с проверкой правдоподобия. Запуск: `node fetch-data.js` |
| `hh-ru.http` | Проверенные примеры HTTP-запросов к API (метро СПб, список городов, метро Москвы) |
| `hh-metro-spb.json` | Скачанный справочник: 6 линий, 75 станций с координатами |

Node.js 18+, без зависимостей.

## Наблюдения и риски

- **Источник вторичный.** HeadHunter ведёт справочник для привязки вакансий к станциям метро, а не как
  транспортные данные; оператор метрополитена к нему отношения не имеет. Новые станции появляются с
  задержкой, но линию 6 (открыта в конце 2024) справочник уже содержит — в отличие от metrobook.
- **Ограничений на частоту запросов для анонимного доступа в документации нет**, но справочник меняется
  редко — достаточно скачивать раз в сутки вместе с остальными источниками.
- **Пересадочные узлы не смоделированы**: «Технологический институт 1» и «Технологический институт 2» —
  просто две станции разных линий с похожими названиями, связи между ними в данных нет.
- **Формат стабилен**: API версионировано на стороне hh.ru и документировано, риск внезапной смены
  структуры минимален по сравнению с парсингом HTML других источников.
