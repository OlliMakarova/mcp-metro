# metro.spb.ru — официальный режим работы станций Петербургского метрополитена

Официальный сайт ГУП «Петербургский метрополитен» — первоисточник **операционных** данных: время работы
вестибюлей, первые и последние поезда, закрытия. Для наших задач достаточно **одного запроса**
`GET https://metro.spb.ru/rejimrabotystancii.html` — на этой странице одна большая HTML-таблица со всеми
станциями всех шести линий. Машиночитаемого API у сайта нет, но таблица разбирается надёжно.

В выгрузке от 26.07.2026: **6 линий, 86 строк-вестибюлей, 84 с временами работы**; переходы между линиями
завершаются в **00:15**; две станции помечены «Станция закрыта на реконструкцию» — «Фрунзенская» и
«Парк Победы» (обе на линии 2).

## Важно: TLS-сертификат Минцифры

Сайт подписан цепочкой «Russian Trusted Root CA» (удостоверяющий центр Минцифры России), которой нет в
комплекте корневых сертификатов Node.js — обычный `fetch()` завершается ошибкой
`SELF_SIGNED_CERT_IN_CHAIN` (в браузерах и curl под Windows сайт открывается, потому что сертификат
установлен в системное хранилище). Вместо отключения проверки сертификата запрос выполняется через
`node:https` с **закреплённым корневым сертификатом** — файл `russian-trusted-root-ca.pem` рядом со
скриптом. Отпечаток SHA-256 закреплённого корня (действителен до 27.02.2032):

```
D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31
```

## Как устроена таблица

Секция каждой линии начинается строкой-заголовком «ЛИНИЯ N», затем идёт подзаголовок с двумя конечными
станциями (направления колонок первых/последних поездов), затем строки вестибюлей:

```
[№, вестибюль, открытие, закрытие входа, закрытие выхода,
 первые к конечной А (нечёт, чёт), первые к конечной Б (нечёт, чёт),
 последние к А, последние к Б]
```

- **Первые поезда даны раздельно по нечётным и чётным датам** календаря — поезда ходят по двум
  чередующимся графикам (то же явление, что и в Москве: `dayType EVEN/ODD` в данных mosmetro.ru).
- **У станции может быть несколько вестибюлей** с разным временем работы (например, «Вестибюль 2 станции
  Ленинский проспект» открыт только 6:30–22:00); времена первых/последних поездов указаны один раз на
  станцию — в строке первого вестибюля.
- **Название вестибюля содержит выход**: «Вестибюль 1 станции Проспект Ветеранов (выход на Дачный пр.)» —
  из этого извлекаются выходы станции.
- **У закрытых станций вместо времён — текстовая пометка** («Станция закрыта на реконструкцию»).
- **Отдельные ячейки содержат несколько времён с пояснениями**: «5:34 нечет / 5:36 чет» (открытие
  различается по чётности даты — «Проспект Просвещения», «Приморская») или «6:30 c 01.08.2026 5:26»
  (плановая смена времени с даты — «Дунайская»). Парсер берёт первое время ячейки — действующее сейчас.

## Бонус: время перегона линии 6 из первых поездов

Линия 6 (Красносельско-Калининская) отсутствует на схеме spb.metrobook.ru, но есть в этой таблице.
Время перегона «Юго-Западная — Путиловская» выводится из разности времени первых поездов на соседних
станциях: первый поезд к Путиловской отправляется от Юго-Западной в 5:42 и проходит Путиловскую в 5:46
(4 минуты); в обратную сторону — 5:49 на Путиловской и 5:52 на Юго-Западной (3 минуты). Среднее —
210 секунд; это значение используется боевым кодом (`src/lib/metro-data/normalize-spb.ts`) для
достройки линии 6 в граф.

## Файлы в этой папке

| Файл | Назначение |
|---|---|
| `fetch-data.js` | Скачивает страницу (с закреплённым сертификатом) и разбирает таблицу в JSON. Запуск: `node fetch-data.js` |
| `russian-trusted-root-ca.pem` | Закреплённый корневой сертификат «Russian Trusted Root CA» для TLS-проверки |

Node.js 18+, без зависимостей.

## Наблюдения и риски

- **Страница для людей, а не для машин.** Вёрстка может измениться в любой момент; в `fetch-data.js`
  стоит проверка правдоподобия (не меньше 60 строк, 5 линий, 50 строк с временами) с понятной ошибкой.
- **Таблица версионируется по датам.** Действующая версия публикуется на той же странице; датированные
  варианты (`rejimrabotystancii<даты>.html`) появляются и исчезают — привязываться нужно к постоянному
  адресу `rejimrabotystancii.html`.
- **Интервалов движения на этой странице нет** — они публикуются отдельной датированной страницей
  (см. таблицу выше) и в этой выгрузке не используются.
- **Времена «через полночь»**: закрытие входа около 0:00–0:45 — при сортировке/сравнении времён работы
  нужно учитывать перенос через полночь (в боевом коде времена до 12:00 трактуются как «следующая ночь»).
- **Плановые изменения внутри ячейки** («6:30 c 01.08.2026 5:26») парсер упрощает до действующего
  значения; при желании будущее значение и дату можно извлекать отдельно — пока необходимости нет.
- **Здесь только вход/выход и первые/последние поезда.** Координат, графа и времён перегонов (кроме
  выводимых косвенно, как для линии 6) на странице нет.
